## Job Creation

To create a job, make a POST request to the Bridge Targeted job creation endpoint:

```
/devices/{deviceId}/jobs
```

Try the API [here]((https://igloocompany.stoplight.io/docs/igloohome-api/8uellqkosv7ry-create-a-bridge-targeted-job)).

### Request

| Parameters | Type                                                                              |
| ---------- | --------------------------------------------------------------------------------- |
| jobType    | integer, see [Job Types](#job-types) for a full list                               |

#### Payload Format

```json
{
    jobType: integer
}
```

### Response

```json
{
  jobId: string
}
```
