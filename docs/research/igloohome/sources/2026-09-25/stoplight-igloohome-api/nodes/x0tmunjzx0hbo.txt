# Bridge API Overview

Bridge devices act as an intermediary between the internet and other devices, allowing for remote access. This can be used for proxied jobs - which target devices through the Bridge, or for jobs which target the Bridge itself.

In addition, Bridge devices support Webhook event notifications for both types of jobs and automated heartbeat events.
